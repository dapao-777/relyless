# 手动冒烟验证清单

覆盖本机无法自动验证的浏览器行为。每条都给了预期结果；不符合即回归。

## 0. 准备

1. `chrome://extensions` → 打开开发者模式 → 加载已解压的 `extension/`。
2. 任意测试页按 `Alt+Shift+S`（或点工具栏图标）开启阅读辅助。
3. 开启前先看 DevTools Console 是否有报错（选项页此前的 `automationSiteEmpty` 报错已修复）。

## 1. 分级语言闸门（决定是否开始扫描）

| 页面 | 预期 |
|---|---|
| 英文文章页 | 出现词注/提示，地址栏旁图标可点 |
| 纯中文页 | 无任何提示；DevTools Network 无 `SUPPORT_BATCH` 请求 |
| 德文/法文/西班牙文页 | 无提示（识别为非英语即停） |
| 中文文章里嵌英文段落 | 英文段落有提示，中文段落没有 |
| 纯数字/乱码页 | 无提示、无报错 |

验证技巧：DevTools → Network 过滤 `SUPPORT_BATCH`/`SENTENCE_GROUPS_BATCH`，非英文页应为 0 次。

## 2. 划词浮条

1. 选中一句英文 → 浮条出现（翻译所选 / 翻译本段）。
2. 点「翻译所选」→ 译文面板出现；再点原文其他位置，浮条不自动回到同一选区。
3. 按 `Escape` 关浮条 → **在原选区内点击/松手，浮条不重新弹出**；重新划选别处，正常弹出。
4. 设置 → 阅读偏好 → 划词动作打开方式选「悬停等待」→ 鼠标停在「翻译所选」上 600ms（默认）自动打开；中途移开取消。
5. 把悬停等待改成 200ms / 3000ms 各试一次，保存后生效。

## 3. 选区快捷键

1. 选中一段英文 → 按 `Alt+Shift+R` → 不出现浮条，直接出译文面板。
2. 只选中一个单词 → 按 `Alt+Shift+R` → 翻译整段（不是单词）。
3. 未开启辅助的页面上直接按 → 自动开启并翻译。
4. `chrome://extensions/shortcuts` 里可改这三个快捷键；改完即时生效，无需重载扩展。

## 4. 段落干净复制

1. 鼠标停在一段英文上（不选中）→ 按 `Alt+Shift+C` → 状态提示「已复制本段原文」；粘贴出来是**纯原文**，没有词注、提示、译文。
2. 选中一句 → 右键「RelyLess：复制选中段落的原文」→ 同样干净。
3. 在有提示注入的段落上复制 → 剪贴板仍不含注入内容（回归重点）。
4. 停在 `<pre>` 代码块上按快捷键 → 提示错误而不是复制代码。

## 5. 站点规则包

1. 设置 → 网站规则 → 粘贴合法包（输入框 placeholder 里的示例）→ 导入成功，列表出现一条。
2. 粘故意写坏的包（如 `exclude:["div[坏"]` 或 `version:2`）→ 导入被拒并逐条显示原因。
3. 导入一条 `exclude:[".sidebar"]` → 访问该站点，侧栏内英文不再有提示；其余站点不受影响。
4. 导入带 `root:"main"` 的包 → 该站点正文识别优先使用 `main`。
5. 带 `lang:"en"` 的包 → 该站点跳过语言检测直接启用（可用一个混合语言站点验证）。
6. 删除规则包 → 行为恢复默认。

## 5.5 追问会话（新）

1. 按住查词键单击一个单词 → 卡片底部出现追问区（输入框 + 追问/停止按钮）。
2. 输入“这里为什么用完成时？”→ 回车或点追问 → 回答**流式**出现在该问题下方；生成中可以点“停止”，已生成部分保留并标“已停止”。
3. 再问第二个问题 → 回答体现上一轮上下文（多轮生效）。
4. 关闭卡片，重新查同一个词 → 历史问答原样恢复（30 天本机保留）。
5. 查同一个站点另一个页面里的同一句话 → 会话不串。
6. 未配置 API 服务时追问 → 卡片里给出明确错误，不崩溃。
7. `providerKind=chatgpt`（登录订阅）时追问 → 提示改用 API 服务（当前订阅链路不支持多轮，属预期）。
8. 隐私窗口追问 → 功能可用但不落盘（重开普通窗口看不到该问答）。
9. 设置 → 阅读记录 → 「对话」标签 → 看到按会话分组的问答（页面标题、选文、每轮问答、删除按钮）；删除后卡片内的历史同步消失。

## 5.6 追问的本地记忆

1. 对一个查过多的词追问“上次怎么讲的？”→ 回答应衔接你此前的笔记（卡片里出现“已结合你过去的 N 条笔记”）。
2. 对新词追问 → 不出现该提示，回答只依据选文与上下文。

## 5.7 间隔重复复习

1. 在一个已有提示记录的词所在页面滚动/停留 → 右下角出现“复习 N”按钮（1 天后该词到期时）。
2. 点按钮 → 面板列出到期词与盒数；点“认识了”→ 该项消失、间隔拉长（3/7/21/60 天）；“还不熟”→ 当天稍后再来。
3. 主动再查一个已排期的词 → 计划重置到第 1 盒（视为遗忘）。
4. 设置里清空本机记录 → 复习入口不再出现（计划键随清理移除见“数据与隐私”）。

## 5.8 Jev 领域识别（Requesty）

1. 设置 → 领域识别 → 选“Jev 判定”→ 填模型 `typesafe/jev-1.13.0`、接口地址与 API Key → 保存（首次会请求 router.requesty.ai 权限）。
2. 打开英文文章 → 领域识别使用 Jev；诊断里 source 显示 `jev`，带置信度分数。
3. 留空模型或 Key 保存 → 明确报错；返回的领域不在支持列表 → 按远程失败回退本地结果（有 warning）。
4. 清除密钥后 → 权限来源里不再包含 router.requesty.ai。

## 5.9 模型路由（实验）

前置：领域识别里已填好 Jev 模型/地址/Key（路由复用同一份凭据）。

1. 设置 → 模型服务 → 「模型路由」打开开关 → 选升级目标（某个已保存服务或 ChatGPT 订阅）→ 保存。
2. 打开英文文章主动查一个词 → 若被判为 premium（段落/救援级/难内容），请求打到升级服务；「统计」行显示“已判 1 次 · 升级 1 次”。
3. 对同一句子再查一次 → 不再判卷（结果缓存或路由缓存命中，统计的“已判”不增加）。
4. 把 Jev 的 Key 清空 → 判卷不可用，请求照常走原服务，统计“判卷失败”或“未启用”。
5. 升级目标选一个没有 Key 的服务 → 自动回落原服务，不报错。
6. 关闭开关 → 统计归零重启，任何请求都不再判卷。

## 6. 选项页

- 模型服务：左侧目录按分组列出（订阅通道 / 主流大模型 / 国内精选 / 开源与推理 / 企业云服务 / 自定义 API），搜索框可按名称过滤；点击任意服务，右侧 Hero 显示图标、简介、默认徽章、获取密钥链接与「检查连接」；「设为默认使用」切换当前服务；订阅项显示订阅面板，API 项显示已保存服务下拉与编辑表单；「自定义服务」按钮走原有新增流程。
- 阅读偏好：划词动作两个单选 + 悬停等待下拉联动（选「点击」时下拉隐藏）。
- 网站规则：规则包导入表单、结果消息、列表删除。
- 使用说明：出现复制快捷键和 Alt+Shift+R 两行新说明。
- Console 无报错（此前 `optionsRenderAutomation` 的 undefined 报错已修复）。

## 已知边界（不是bug）

- 追问只支持 API 服务（`providerKind=chatgpt` 登录订阅会提示改用 API）；订阅原生链路加多轮需要连接器同步更新，未做。
- 追问记录不随阅读记录导出（两套存储；导出文件只含阅读事件）。
- 视频字幕线仍未启用（`VIDEO_SUPPORT_ENABLED=false`）；启用前需在真实 YouTube 页面按「播放页 → SPA 进入 → 字幕开关」三步实测。
- 英文页中完整的德语/西语段落仍会获得提示（块级判定基于字符占比）。
- 划词快捷键复用浏览器命令体系，录制自定义组合键需到 `chrome://extensions/shortcuts`。
