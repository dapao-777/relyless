# ADR 0000：决策标题

- 状态：proposed
- 日期：YYYY-MM-DD
- 参与讨论：GitHub 用户名或相关 Issue
- 取代：无
- 被取代：无

## 背景

描述必须做决定的问题、现有限制和已知事实。

## 决策驱动因素

- 用户价值或产品边界
- 隐私、权限与费用
- 浏览器和兼容性约束
- 维护与验证成本

## 备选方案

### 方案 A

说明方案及主要权衡。

### 方案 B

说明方案及主要权衡。

## 决策

写明选择什么，以及为什么它优于其他方案。

## 结果

### 正面影响

列出获得的能力或降低的风险。

### 代价与风险

列出新增复杂度、限制和需要持续承担的成本。

## 实施与验证

列出执行该决定所需的 PR、迁移、验证和退出条件。
