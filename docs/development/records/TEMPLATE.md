# 开发记录：主题

- 日期：YYYY-MM-DD
- 状态：进行中 / 已交付 / 已回退
- 相关 Issue：链接或“无”
- 相关 PR：链接或“待提交”
- 相关 ADR：链接或“无”

## 背景

说明用户问题、现有行为和为什么现在需要处理。

## 目标

列出本次交付后可观察到的结果。

## 非目标

写明本次不会顺带解决的内容，避免范围在实现中扩张。

## 实现边界

说明涉及的运行时、模块、消息契约和兼容策略。只记录无法从 diff 直接理解的部分。

## 数据、权限与费用

说明新增或改变的数据发送、存储、生命周期、浏览器权限、模型请求和费用行为；没有变化时明确写“无变化”。

## 风险与回滚

列出主要失败模式、监测方式和安全回滚方法。

## 验证证据

- 自动检查：命令和结果
- 浏览器冒烟：场景和结果
- 无障碍/视觉：适用时填写

## 后续事项

只记录已经确认但不属于本次范围的事项；没有则写“无”。
